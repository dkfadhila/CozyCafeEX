# Cozy Cafe EX

A cozy 3D cafe game in the browser: pick a chef, take orders from customers, cook, serve and keep the cafe running.
Built with Vite, React, TypeScript and three.js.

## Controls

- Move: W A S D
- Interact: E
- Camera: drag or Z / C
- Zoom: mouse wheel
- Reset camera: R
- Pause / settings: Esc

## Develop

```bash
npm i
npm run dev
```

## Build

```bash
npm run build     # type-check + production bundle in dist/
npm run preview   # serve dist/ locally
```

Deploys to Vercel as a static Vite app (see `vercel.json`).
